Organization

How This Project Is Organized

Structure of the Website

Our group decided to organize the website by focusing on individual Mesopotamian demons. We chose this approach because each demon has distinct characteristics, beliefs, and roles within Mesopotamian society. Studying them separately allows us to examine each demon in depth and identify connections and differences among them. We also decided to include a separate overview page about exorcists because of their relevance to Mesopotamian demons. Finally, the website will include a complete bibliography of the sources used throughout our research.

  • Gallu
  • Lamashtu
  • Lilitu
  • Pazuzu
  • Exorcists
  • Sources

Layout of Each Demon Page

Each demon page is divided into four parts: an introduction to the demon, how the demon affected Mesopotamians, artifacts associated with the demon and their meanings, and rituals involving the demon.
